# 抖音开发者工具加载故障对比包

## 范围与隐私

此包汇总本机当前及重置前可取得的开发者工具磁盘日志、插件缓存和基础库快照；不是保证捕获所有进程和网络事件的完整追踪。未修改 Unity 项目、打包产物或开发者工具文件。

**01_原始日志_含敏感信息 中为未经脱敏的原始日志，可能包含登录凭据、请求参数、账号和本地路径。只在可信内部传递，不直接发布到论坛或公开工单。** 插件源码、基础库也请仅内部分析，保留许可证。

## 文件说明

- 01_原始日志_含敏感信息：当前 vela 日志、重置前 vela.backup 日志、工具安装目录日志（有些源文件为空属正常情况）。
- 02_插件缓存_本机、03_插件缓存_同事包：四个插件文件，含入口、配置、签名和许可证。
- 04_基础库：本机已下载版本的 tmg-core.js，不代表这些版本都在当前运行中使用。
- 环境信息.json：工具路径、版本、系统版本及采集时间。
- 文件校验清单.tsv：本次快照文件的 SHA256，方便与正常电脑逐项比对。
- 控制台_用户提供.txt：用户提供的 Console 错误，非程序直接导出的原始 Console。
- 加载链路分析.md：从基础库实际代码提取的观察与待确认项。

## 正常电脑如何对比

1. 用完全相同的 tt-minigame 包测试，记录游戏包版本/哈希、工具版本、基础库选择、设备/运行模式、账号 AppID 与 Windows 版本。不要以“同一 Unity 项目”替代“相同导出包”。
2. 在正常电脑采集对应 AppData/Roaming/@byted/vela/logs、tempFile/pc-sdk/micro-plugin-packages/tt674511f8f84ea91612/online 和实际使用的 tmg-core.js。
3. 对照环境信息.json 和文件校验清单.tsv，先比工具版本、插件和基础库哈希。相同插件文件不代表注册到相同运行上下文。
4. 正常与故障机均重新启动项目，Console 开启 Preserve log/保留日志，从最初启动开始保存全部输出；Network 开启保留日志，导出 HAR（HAR 同样可能包含凭据，内部保管）。
5. 比较插件入口请求的实际 URL/协议、请求状态、响应大小、脚本执行上下文，以及 requirePlugin 前后模块注册情况。记录 inject success 与 UnityManager.version 是否都出现。
6. 本包不包含抓取到的 HAR，也未通过调试器捕获插件注册函数的运行时参数；这些需两机补充，不能从现有文本假定。

重置前用户数据仍在原 AppData 下的 vela.backup-20260910-141525，未删除。不要为对比将整份用户目录互拷到其他电脑，以免迁移登录凭据与机器专属状态。

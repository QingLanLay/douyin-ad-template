## 关键发现

本机缓存的 microgame/4.29.0.3/tmg-core.js 中 requirePlugin 的路径为：

1. 从游戏配置取得 provider，拼出 __plugin__ + provider + / + index.js。
2. 发现模块表中没有入口时，先打印 plugin ... inject success!。
3. 再调用 globalThis.loadScript(wkpluginfile://...) 或原生 plugin.load(...)，取决于运行分支。
4. 随后解析模块路径。

因此 inject success! 在该实现中不是“模块注册已验证成功”的证据。现有堆栈证明后续解析失败，不足以确定究竟是加载没有执行、注册失败、注册到其他上下文还是被重置。

afterLoadGameJS 调用来自安装目录内 extract-miniapp-page/vendors-pcsdk*.js 的页面模板；之前曾出现回调未定义。该错误是否与当前模块解析故障同因，尚未确认。
